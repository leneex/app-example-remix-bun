# Remix на Bun

Пример приложения [Remix](https://remix.run/) на [Bun](https://bun.sh/).

## Параметры деплоя

Выберите рантайм **Bun**, фреймворк **Remix** и тип приложения **frontend**. Для frontend будет опубликована статическая сборка.

| Параметр | Значение |
| --- | --- |
| Фреймворк | Remix |
| Версия Bun | 1.2 |
| Тип приложения | `frontend` |
| Команда сборки | `bun run build` |
| Директория сборки | `build/client` |

Remix на Bun поддерживается только как статический frontend. SSR для этой пары в каталоге API отсутствует.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build
```
