# Remix на Bun

Пример приложения [Remix](https://remix.run/) на [Bun](https://bun.sh/).

Remix v2 продолжает развиваться как [React Router](https://reactrouter.com/) в режиме фреймворка,
поэтому пример собран на React Router 8.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/build/client` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack видит `bun.lock` и
собирает проект через Bun: `bun run build` запускает `react-router build`. Серверный рендеринг
выключен (`ssr: false` в `react-router.config.ts`), страницы пререндерятся в HTML при сборке,
готовые файлы — в `build/client`. Страница в демо одна, поэтому SPA не нужен — несуществующий
адрес отвечает 404.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build
```
